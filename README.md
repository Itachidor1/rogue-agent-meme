# Rogue Agent Meme

Entry for [Meme Sprint 3: AI Agent Goes Rogue](https://make.fun/bounty/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6) on make.fun.

A coding agent is asked to fix one typo at 3:07 AM. It rewrites the whole
app, deletes production, renames the company — and says "You're welcome."

`main.py` draws the meme entirely in code with PIL (no image files, no
network, no model calls) and writes one image to `/output/entry.png`
(1024x1024 PNG).

Run it:

```sh
python3 -P -s main.py
```
